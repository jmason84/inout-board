IN/OUT Board

A simple, self-hosted board that shows who is in and who is out, for offices, plazas and shared buildings. Every tenant on one page, with each person choosing what they share.

Try the live demo View on GitHub Run it yourself

What it does

Built for a building full of different businesses, where the front desk, the tenants and the visitors all need the same simple answer: is this person in right now?

Every tenant on one page

The public board lists each company with its logo, office and contact details, then its people with a clear IN / OUT status and one big button.

Privacy by choice

Name, title, picture and status are always shown. Office, phone and email appear only when the person (or an admin) switches them on. Search never matches phone numbers.

Photo, logo or initials

People pick which picture appears next to their name. Tenant managers keep their company's logo and details up to date themselves.

Five layouts

Table, list, cards, tiles and the classic in/out board. Visitors choose; admins set the default. Large-text mode and dark mode included.

An admin console that stays out of the way

Live board, tenants, people, time log with shifts and hours, manual corrections, CSV export, and per-admin accounts.

CSV import and export

Load every person from a spreadsheet with a preview and a plain-English problem list before anything is written. Export everyone back out any time.

Accessible by design

Keyboard friendly, screen-reader labels, text statuses instead of colour alone, big touch targets. Automated WCAG 2.1 AA checks pass on every page.

Self-hosted and dependency-free

One Node.js process and one SQLite file. No database server, no npm install. Docker, systemd and backup scripts are included.

The public board

Pick the layout that suits the screen: a directory table, a simple list, photo cards, or big touch tiles for a wall tablet.

Each person controls their own profile

People sign in to their own page to choose their picture and exactly which contact details others can see. A live preview shows how they will appear.

The admin console

Everything an administrator needs, one click away, with the same keyboard-friendly, high-contrast design.

Run it yourself

It is one Node.js process (22.5 or newer) and one SQLite file. The fastest way is Docker:

git clone https://github.com/jmason84/inout-board.git
cd inout-board
cp .env.example .env        # set ADMIN_USER and a strong ADMIN_PASSWORD
docker compose up -d        # then open http://localhost:3000

Or with plain Node, no install step:

ADMIN_USER=admin ADMIN_PASSWORD='a-long-passphrase' node server.js

The deployment guide covers HTTPS, Cloudflare Tunnel, systemd, backups and upgrades.

About this demo. GitHub Pages can only serve static files, so this demo runs the real front end against a small backend that lives in your browser, using made-up people and companies. Nothing you do here is sent anywhere, and the banner has a Reset button. CSV import and a few security features are switched off in the demo; the real server has them all.
